# ТУТБЛОГЕРЫ.РФ

Веб-интерфейс для ведения рекламных кампаний с блогерами.

## Запуск

Откройте опубликованный сайт или запустите локально:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4174/

## Проверка

```sh
node logic-check.cjs
```

## Публикация

GitHub Pages публикует корень ветки main. После обновления main дождитесь завершения публикации в Actions.

## Возможности и ограничения

- Кабинеты рекламодателя и блогера переключаются через меню аккаунта.
- Профили, кампании и показатели в исходных примерах вымышлены.
- Данные и переписка сохраняются в localStorage конкретного браузера.
- Загруженные видео хранятся в IndexedDB конкретного браузера.
- На новом адресе сайта создается отдельное хранилище: данные с localhost автоматически не переносятся.
- Серверной регистрации, многопользовательского обмена, банковских переводов и интеграций с соцсетями нет.
- Сообщения команде и обращения не отправляются внешним получателям.

Название проекта не означает, что сайт размещен на отдельном домене тутблогеры.рф.
